# Saroz Threadz — website

A rebuild of [sarozthreadzjaipur.com/factory](https://sarozthreadzjaipur.com/factory/) as a
fast, indexable, self-hosted static site, replacing the Canva-exported single page.

**Why the rebuild:** the old page was a Canva export — a ~200 KB JavaScript bundle that
renders the entire site client-side. It has no crawlable text, no per-page URLs, no
metadata, no `sitemap.xml`, and every heading and paragraph is locked inside a Canva
design file. For a B2B manufacturer whose buyers arrive from Google searches like
*"garment manufacturer Jaipur embroidery"*, that is a commercial problem, not a
cosmetic one.

## Stack

Deliberately none. Hand-written HTML, one CSS file, one 3 KB JS file for progressive
enhancement. The site works with JavaScript disabled.

- No framework, no npm, no lockfile, no CI build to break.
- Self-hosted fonts (no Google Fonts request, so no third-party call from EU visitors).
- Total page weight: roughly 400 KB for the homepage above the fold, ~2.9 MB of assets
  for the whole site, all locally served WebP.
- Deploys to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any bucket.

`build.py` stitches a shared header/footer/CTA around per-page content and writes the
HTML. It exists so the nav and footer live in one place, not so the site needs a build:
the generated `.html` is committed, and the host serves it directly.

## Working on it

```bash
python3 build.py          # regenerate the HTML from build.py, then commit the output
python3 -m http.server 8000   # preview at http://localhost:8000
```

Copy lives in `build.py`, one function per page. Design tokens (colour, type scale,
spacing) are the custom properties at the top of `assets/css/site.css` — change those
rather than individual rules.

```
assets/js/site.js     Nav drawer, scroll reveal, mailto RFQ
assets/img/…          WebP, resized from the client's originals

vercel.json           Headers + caching (netlify.toml mirrors it)
```

## What was carried over, and what was not

Every factual claim on the site — 200,000 sq. ft., 600 single-needle lockstitch UBT
machines, 45 four/five-thread and 10 flat machines, SMETA, BCI, Disney licensing,
Government of India export house recognition, the Sitapura address and contact details —
comes from the client's existing page. Photography and the hero video are the client's
own assets, re-encoded to WebP/MP4.

Nothing was invented. Where the old page said "over 40 years" the new site says the same
rather than naming a founding year; there are no fabricated lead times, opening hours,
client names, or testimonials. Placeholders that should be confirmed before launch are
listed in `TODO.md`.

## Accessibility & SEO

- One `<h1>` per page, semantic landmarks, skip link, visible focus rings.
- Every image has alt text; `prefers-reduced-motion` disables reveal animations.
- Light and dark themes, both explicitly painted.
- Per-page `<title>`, meta description, canonical, Open Graph, and Organization JSON-LD.
- `sitemap.xml` and `robots.txt` generated by `build.py`.
- Verified at 390 / 768 / 1440 px: no horizontal overflow, no console errors, no 404s.
