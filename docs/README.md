# Client documents

## `saroz-threadz-website-phase-plan.pdf`

The phase plan for Saroz Threadz: what Phase 1 delivered, the three phases that
remain, the three-to-four-week schedule, the five roles delivering it, and the
list of things only the client can supply. Written for a non-technical reader —
Next.js, hosting and AI search are all explained in plain language.

`phase-plan.source.html` is the source. It is a single self-contained HTML file
with print styles (A4, ten pages, one section per page). To regenerate the PDF
after editing it, print the file to PDF from a browser with background graphics
on and margins set to 16mm top / 18mm bottom / 15mm sides.

If a section grows past one page it will spill onto a mostly-empty next page —
check the page breaks after any edit.
